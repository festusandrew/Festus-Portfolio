# Sawad Website Clone

This is a premium, high-fidelity clone of the **Sawad** Framer portfolio website (https://sawad.framer.website/). It has been built using semantic HTML5, modern layout techniques (CSS Grid & Flexbox), and interactive vanilla JavaScript.

## Features

- **Dark Mode Aesthetic:** Rich dark background (`#151312`) styled with neon lime (`#c5ff41`) and coral orange (`#f46c38`) accents.
- **Floating Glassmorphic Header:** Floating navigation bar with Backdrop blur (`blur(16px)`) and responsive desktop/mobile toggle.
- **Custom Cursor:** Custom dual-element trailing cursor script designed for desktop, featuring interactive hover scaling and color shifts.
- **Background Glows:** Muted radial gradients in the page corners providing depth and visual appeal.
- **Scrolling Marquee Trackers:** Double-moving horizontal banners displaying design highlights and development skills.
- **Premium Cards & Grids:** Scale-on-hover card systems for Projects, Premium Tools, Work Experience, and Blog Posts.
- **Interactive Contact Form:** Functional client mockup form including budget dropdown and submission transition to success state.
- **Fluid Responsiveness:** Adaptive styling built for Breakpoints: Desktop (1440px+), Laptop (1080px), Tablet (810px), and Mobile (<809px).

## Project Structure

```
sawad-portfolio-clone/
│
├── index.html     # Page layout & typography linkage
├── style.css      # Core styles, animations & responsive breakpoints
├── app.js         # Interactive behaviors (scrollspy, menu, custom cursor, contact state)
└── README.md      # Documentation
```

## Running the Project

To run this project locally, simply open the `index.html` file directly in any modern browser, or run a local development server such as VS Code's Live Server or Node's `http-server`:

```bash
# Using http-server
npx http-server .
```
